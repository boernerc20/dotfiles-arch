# CLAUDE.md

Guidance for Claude Code working in this repo. See `README.md` first for what
this project actually is; this file is about not re-breaking things that were
already fixed once.

## What this repo is

Personal Hyprland dotfiles, tracked across two machines (a desktop and a
laptop) via `dotfiles-sync` (`git pull` + `install.sh`, idempotent). The
desktop is the source of truth; the laptop only ever pulls.

## Rules that exist because something broke before

- **Never hand-edit `~/.config/waybar/style.css`, `~/.cache/wal/*`, or
  `~/.config/rofi/colors-rofi.rasi`.** All three are rebuilt from a template
  every time `~/.local/bin/wal-hypr.sh` runs and are gitignored. Edit the
  *template* — `.config/waybar/style-base.css`, `.config/wallust/templates/`
  — never the rendered output.
- **Nerd Font icons: use nf-md codepoints (U+F0000+), not BMP PUA (U+E000–F8FF)
  where an nf-md equivalent exists.** BMP PUA glyphs have been silently
  stripped to empty strings in this repo before (`config.jsonc` shipped with
  `"format-icons": ["", "", ""]` at one point). Where no nf-md equivalent
  exists (distro logos, weather icons) BMP PUA is unavoidable and just a
  `note` from the checker, not an `error`. After touching any icon in
  `.config/waybar/`, run:
  ```sh
  python3 .config/waybar/scripts/verify-glyphs.py
  ```
  It checks both `config.jsonc` and `config-laptop.jsonc`, fails on empty
  icon strings, and fails on BMP PUA use in either config file specifically.
- **Never hardcode a machine-specific value in a *shared* (tracked) file.**
  This has broken things at least three times: `hardware.sh`'s GPU-only
  fourth field, `net-sparkline.py`'s NIC name, and `01-monitors.conf`
  carrying the desktop's exact monitor line. The fix pattern is always
  auto-detection at runtime (`command -v nvidia-smi`, `/proc/net/route`,
  `hostnamectl chassis`) — never a second hardcoded value for the other
  machine. If a value truly cannot be detected, it belongs in
  `hyprland-local.conf`, not a tracked file.
- **`hyprland-local.conf` must be sourced *last*** in `hyprland.conf` (monitor,
  touchpad, GPU env, machine-only autostart) so it overrides the shared
  `conf.d/` files rather than being overridden by them. This was missing
  entirely for a long time — the file was generated by `install.sh` on every
  machine but never actually loaded.
- **A secret goes in `~/.config/shell/secrets.env` or
  `~/.config/waybar/weather.env`, never in `.zshrc_copy` or any tracked
  file.** Two live API keys sat in this public repo for four months from
  exactly that mistake. If you ever see a real-looking key, token, or
  password in a diff you're about to commit, stop and ask.

## Before committing

- Run `.config/waybar/scripts/verify-glyphs.py` if any waybar file changed.
- If `install.sh` changed, run `bash -n install.sh` — it's long enough that a
  quoting mistake can hide past a casual read.
- Check `git status` for drift beyond what you intended to touch. This repo
  has repeatedly accumulated real, uncommitted local changes for months at a
  time (hypridle re-enable, DDC/CI brightness, RGB sleep hook all sat
  uncommitted on the desktop; a March-dated diff sat uncommitted on the
  laptop for five months) — if you're in here for one fix, it's worth a
  glance at whether something else nearby is also dangling.
